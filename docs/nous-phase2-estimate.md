# 노스 Phase 2 — 실시간 AI 상담 기능 견적

작성 2026-10-17. 요청: `nous_member_card/작업지시서.md` §8. 아직 만들지 않는다 — 규모·비용을 가늠하고 방향을 정하기 위한 문서.

## 결론

**옵션 B(서버리스 경량 백엔드)를 권한다.** 이 사이트는 이미 Cloudflare Pages Functions(`/api/visits`, `/oauth/*`)를 쓰고 있어 같은 자리에 `/api/chat`을 더하면 된다. 인프라 추가 비용은 사실상 0원이고, 운영비는 LLM 호출비가 전부다. 월 대화 50건이면 Claude Opus 5.5로도 **월 약 1만 5천 원 이하**다.

| | A. 노스(Hermes) 게이트웨이 재사용 | **B. Cloudflare Functions + Claude API** | C. 임베드형 챗봇(Chatbase·Crisp 등) |
|---|---|---|---|
| 개발 기간 | 4–6일 + 보안 강화 | **8–11일** | 1–2일 |
| 인프라 월 비용 | 0원(개인 PC 전기료) | **0원**(기존 Pages 무료 한도 안) | 요금제별 월 수십 달러대(가입 시 확인) |
| 가동률 | PC가 꺼지면 중단 | **24/7** | 24/7 |
| 보안 | 개인 PC를 공개 트래픽에 노출 — 위험 큼 | API 키는 Cloudflare 비밀값, PC와 분리 | 대화 데이터가 외부 업체에 저장 |
| 랩 지식 반영 | 노스가 이미 앎 | **사이트 콘텐츠를 빌드 때 자동 주입 — CMS 수정이 곧 반영** | 문서를 업체에 따로 올리고 갱신 |
| 디자인 통일 | 직접 구현 | **모달 안에 사이트 톤 그대로** | 업체 위젯 모양 제약 |

A는 PC가 꺼지거나 노스가 다른 작업 중이면 상담이 끊기고, 공개 웹에서 들어오는 프롬프트 인젝션이 PC 안의 노스 권한(파일·메일 등)에 닿을 수 있어 권하지 않는다. C는 빠르지만 대화 기록이 외부 업체에 쌓이고 교수님께 전달하는 흐름을 맞추기 어렵다.

## 옵션 B 구성

```
[노스 모달] ── 채팅 UI(음성 소개 아래 "노스에게 물어보기")
     │  POST /api/chat (스트리밍)
     ▼
[Cloudflare Pages Function]
  · Turnstile 봇 확인 · IP별 속도 제한(KV) · 입력 길이 제한
  · 시스템 프롬프트 = 빌드 때 만든 연구실 지식 JSON(연구 주제·멤버·모집·최근 논문)
  · Claude API 호출(Opus 5.5, effort low, 프롬프트 캐싱)
     │
     ├─ 대화 로그 → D1(또는 KV), 보관 기간 지나면 자동 삭제
     └─ 대화 종료 시 요약 1회 호출 → 교수님께 텔레그램 알림 또는 메일
```

- **지식 갱신**: Astro 빌드 때 `getCollection`으로 연구 주제·멤버·News·논문 요약을 JSON으로 내보내 시스템 프롬프트에 넣는다. 교수님이 CMS에서 내용을 고치면 다음 배포(2분 이내)부터 노스가 그 내용으로 답한다. 따로 할 일 없음.
- **모르는 질문**: 지식 JSON에 없는 내용(인건비 액수, 개인 사정 등)은 추측하지 않고 "교수님께 직접 문의해 주세요" + 메일 버튼으로 넘기도록 프롬프트에 고정.
- **도구 없음**: 노스 챗봇은 답변만 하고 파일·메일·웹 접근 도구를 주지 않는다. 프롬프트 인젝션이 성공해도 할 수 있는 일이 "이상한 답변" 하나뿐이라 위험이 작다.

## LLM 비용

가격(Anthropic API, 2026-10-06 기준, 100만 토큰당): Opus 5.5 입력 $4 · 출력 $20 · 캐시 읽기 $0.20 / Sonnet 5.5 $2 · $10 · $0.20 / Haiku 5.5 $0.10 · $0.50.

**대화 1건 가정**: 연구실 지식 시스템 프롬프트 약 1.5만 토큰(캐싱), 6턴, 턴당 사용자 질문 + 누적 대화 약 2천 토큰, 답변 약 300토큰 + 사고 약 200토큰, 종료 요약 1회.

| 모델 | 대화 1건 | 월 50건 | 월 300건 |
|---|---|---|---|
| **Claude Opus 5.5**(기본 권장) | 약 $0.23(약 320원) | 약 $12(약 1.6만 원) | 약 $70(약 9.5만 원) |
| Claude Sonnet 5.5 | 약 $0.13 | 약 $6 | 약 $38 |
| Claude Haiku 5.5 | 약 $0.01 | 1달러 미만 | 약 $3 |

- 계산: 첫 턴 캐시 쓰기 1.5만×1.25×$4/M ≈ $0.075, 턴당 캐시 읽기 $0.003 + 비캐시 입력 $0.008 + 출력 $0.010 ≈ $0.021 × 6턴 ≈ $0.13, 요약 ≈ $0.03. 환율 1,350원 가정.
- 방문이 드물면 대화마다 캐시가 식어(기본 5분) 첫 턴에 캐시 쓰기를 다시 낸다 — 위 표는 이 최악 경우를 넣은 값이다.
- **월 대화 수 추정**: 연구실 사이트 월 방문 수백~천 회 × 채팅 시작률 2–5% ≈ 월 10–50건. 모집 시즌에 늘어도 수백 건 수준.
- 모델 선택은 교수님 몫이다. 답변 품질이 연구실 첫인상이라 기본은 Opus 5.5(effort low)로 두고, 실제 대화 30–50건으로 Sonnet 5.5와 품질을 비교한 뒤 바꿀지 정하는 것을 권한다. Anthropic 콘솔에서 **월 지출 한도**(예: $30)를 걸어 두면 악용 시에도 비용이 그 이상 나가지 않는다.

## 보안·악용 방지 추가 공수

위 공수표의 1.5–2일에 포함. 구성: Cloudflare Turnstile(무료, 첫 메시지 전 1회), IP당 분당·일당 메시지 상한(KV), 메시지 1개 1,000자·대화 1건 20턴 상한, 시스템 프롬프트에 범위(연구실 안내) 밖 요청 거절, 도구 미부여. 욕설·혐오 필터는 모델 자체 거절로 대부분 걸러지므로 별도 필터는 두지 않고 로그로 확인.

## 유지보수 난이도

- **내용 변경**: CMS 수정만으로 자동 반영(별도 작업 없음). 가장 큰 장점.
- **답변 말투·정책 변경**: 시스템 프롬프트 파일 한 곳 수정 → 배포. Claude Code로 몇 분 작업.
- **모델 교체**: 설정값 하나. 새 모델이 나오면 질문 세트로 품질 확인 후 교체.
- **월 점검**: 콘솔 사용량·로그 훑어보기 10분.

## 정하실 것 (구현 전에)

1. **모르는 질문 처리** — 제안: 추측 금지, "교수님께 직접 문의" + 메일 버튼.
2. **대화 기록 보관 기간** — 제안: 90일 뒤 자동 삭제, 교수님께 보낸 요약만 남김. 방문자가 이메일 등을 남기면 개인정보 수집·이용 동의 문구 필요.
3. **언어** — 제안: 한국어·영어 모두(추가 비용 없음, 질문 언어로 답).
4. **알림 채널** — 텔레그램(지금 노스가 쓰는 봇) 또는 메일.
5. **모델** — 기본 Opus 5.5, 품질 비교 후 Sonnet 5.5 전환 여부.
