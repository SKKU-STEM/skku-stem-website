# 노스(Nous) AI 연구보조원 카드 — 설계

작성 2026-10-16. 원 요청: `nous_member_card/작업지시서.md` (노스 작성, 2026-10-15). 이 문서는 그 지시서를 사용자와 검토해 확정한 판이며, 둘이 다르면 이 문서가 우선한다. §10의 "제 판단" 항목들도 사용자에게 정리본으로 보여 주고 승인받았다(2026-10-16).

## 1. 의도

연구실 조인을 고민하는 학생이 사이트에서 "노스"를 누르면 80초짜리 영어 음성 소개를 듣고, 끝에서 김영민 교수님께 메일로 상담을 요청하도록 이끈다. 노스는 AI이며, 사진이 실제 사람처럼 보이므로 **방문자가 실제 대학원생으로 오해하지 않게 AI임을 분명히 표시**하는 것이 이 작업의 전제다.

## 2. 목표 · 비목표 · 반목표

목표
- People 페이지와 메인 "Now recruiting" 섹션 두 곳에 노스 진입점을 둔다. 둘 다 같은 모달을 연다.
- 모달 = 사진 확대(떠오름) + 음성 재생 + 말하는 모션 + 문단 자막 + 차트 2개 + 종료 후 상담 CTA.

비목표 (이번 범위 아님)
- 실시간 AI 채팅(지시서 §8 Phase 2). 견적 문서만 구현 후 별도로 쓴다.
- 입모양 스프라이트, AI 립싱크 영상, 한국어 음성.
- 노스를 CMS에서 편집 가능하게 만드는 것.

반목표 (기술적으로 돌아가도 실패)
- 노스가 사람 멤버처럼 보이는 것 — AI 표시가 카드·모달 어디에서도 빠지면 실패.
- 사실과 다른 수치가 화면에 오르는 것. 제공된 `chart_careers.png`·`chart_ai_semicon.png`는 **쓰지 않는다**(아래 §5).
- 페이지 첫 로드가 무거워지는 것 — 음성(640KB)은 모달을 열 때만 받는다.

## 4. 동작 명세

### 4-1. 진입점
- **People 카드**: 기존 멤버 카드(`lift-card comet-card rounded-lg border border-cream-300 p-6`, 좌 텍스트 / 우 `w-24` 3:4 사진)와 같은 골격. 텍스트는 `노스` / `Nous` / `AI Research Assistant` / `SKKU-STEM Lab 상주 AI 어시스턴트`. 이름 옆이나 사진 모서리에 **`AI` 배지**. 하단에 "▶ 연구실 소개 듣기 · 1:19" 버튼. 카드 전체가 하나의 `<button>`(또는 카드 안 버튼 + 사진 클릭 모두 열림) — 키보드로 열 수 있어야 한다.
- **메인 카드**: 오른쪽 열 아래칸. 가로형 — 사진 썸네일(3:4, 약 72–96px 폭) + "AI 연구보조원 노스가 연구실을 소개합니다" + "▶ 연구실 소개 듣기 · 1:19" + `AI` 배지. 영상 박스와 폭을 맞춘다. 문구는 한국어(섹션이 `lang="ko"`).

### 4-2. 모달 (하나의 컴포넌트, 페이지당 1개 인스턴스)
- 네이티브 `<dialog>` + `showModal()` (Esc 닫기·포커스 가둠은 브라우저 기본). 기존 `SearchDialog.astro`의 `<dialog>` 패턴을 따른다.
- **열 때 — 떠오름**: 클릭한 진입점 사진의 화면 좌표에서 모달 속 큰 사진 자리로 FLIP 애니메이션(Web Animations API, 350ms ease-out). 모달 사진은 썸네일보다 1.4–1.6배 이상 크게 보이고 그림자(`shadow-lift` 계열)로 떠 있는 느낌. 백드롭은 ink 반투명 페이드.
- **재생**: 열자마자 `audio.play()` (사용자 클릭 직후라 자동재생 정책 문제 없음). `play()`가 거부되면 재생 버튼을 눌러 시작할 수 있게 둔다(에러 삼킴 금지, 버튼 상태로 표시).
- **말하는 모션**: 오디오 `play`/`pause`/`ended` 이벤트로 사진 래퍼에 `is-talking` 클래스를 토글. `@keyframes talk-pulse`: scale 1↔1.02 + 코랄 글로우(box-shadow) 강도 변화, 주기 약 0.9–1.2s.
- **컨트롤**: 재생/일시정지 버튼, 진행 막대(현재/전체 시간). 스크럽은 선택 — 넣는다면 `<input type="range">`.
- **자막**: 지시서 §5 스크립트 5문단을 transcript 패널로 표시하고, 재생 위치에 해당하는 문단을 강조(나머지는 흐리게), 패널 안에서 자동 스크롤. 문단 시작 시각(실측, 아래 §6)으로 판정. 전체 원고가 늘 DOM에 있으므로 스크린리더에 노출된다(검색 색인은 아래 Pagefind 항목대로 제외).
- **차트 등장**: 문단 3 시작(AI 반도체 이야기)에 AI 반도체 차트, 문단 4 시작(졸업생 진로)에 진로 차트가 페이드인. 한 번 나타난 차트는 남는다. 사용자가 진행 막대로 앞쪽에 가면 이미 나온 차트는 그대로 둔다(되감기에 사라질 필요 없음).
- **CTA**: `ended` 이벤트 후 모달 하단에 고정 표시, 다시 재생해도 남는다.
  ```
  연구실 조인에 관심 있으신가요?
  Prof. Young-Min Kim (김영민 교수)에게 메일을 보내 상담받아 보세요.
  youngmk@skku.edu   ← mailto 링크
  ```
  지시서의 📧 이모지는 사이트 톤(SVG 아이콘 사용)에 맞춰 기존 Contact 버튼의 메일 SVG로 대체.
- **AI 고지**: 모달 하단 작은 글씨 "노스는 AI 연구보조원입니다. 사진과 음성은 AI로 생성되었습니다." + 차트 출처 각주(§5).
- **닫기**: X 버튼, 백드롭 클릭, Esc. 닫으면 `pause()` + `currentTime = 0`, 차트·CTA·자막 상태 초기화(다시 열면 처음부터).
- **레이아웃**: 데스크톱 = 좌 사진·컨트롤 / 우 자막, 아래 차트 2개 나란히, 그 아래 CTA. 모바일(<640px) = 세로 한 줄로 쌓고 모달은 화면 폭 거의 전체, 모달 내부 세로 스크롤. 가로 오버플로 0.
- **reduced-motion**: FLIP·펄스·페이드 끄고 즉시 표시(차트는 해당 문단에 그냥 나타남).
- **Pagefind**: 모달은 두 페이지에 중복되므로 두 페이지 모두 모달 전체를 `data-pagefind-ignore` 처리한다. 원고 문구는 사이트 다른 곳(PI 소개·Research)과 겹쳐 색인 이득이 적다.

## 5. 차트 2개 (둘 다 빌드 시 생성되는 인라인 SVG, 사이트 토큰 색)

색은 `global.css` 토큰만 쓴다(cream / ink / coral 스케일). 다크 배경 PNG 톤은 쓰지 않는다. 사이트에 다크 모드는 없다.

### 5-1. 졸업생 진로 (자동 집계)
- 소스: `getCollection('members')`에서 `section === 'alumni'`인 항목의 `currentAffiliation`. 여러 소속이 `;`로 이어져 있으면 **첫 항목**이 현재 소속(예: 한경탁 `LG Energy Solution (2024–present); Samsung Electronics (2020–2023)`).
- 분류 규칙(키워드, 대소문자 무시) — 2026-10-16 데이터 기준 실측 결과를 함께 적는다.

| 범주 | 키워드 | 현재 해당 |
|---|---|---|
| 반도체·배터리 대기업 | Samsung, LG Energy Solution, SK Hynix | 6 (삼성 2, LG엔솔 2, SK하이닉스 2) |
| 장비·소재 기업 | Lam Research, SEMES, ENF | 4 (Lam 2, SEMES 1, ENF 1) |
| 국내 연구기관 | KIST, KRISS, NNFC / National Nanofab | 3 |
| 대학 | KAIST, University | 2 (KAIST, 동신대) |
| 해외 연구기관 | Oak Ridge, ORNL | 1 |
| 기타 | 위에 안 걸린 것 | 0 |

  - 키워드 충돌 주의: `KIST`는 `KAIST`의 부분 문자열이 아니지만(A가 끼어 있음) 단어 경계로 매칭할 것. 범주 판정 순서는 표 순서.
  - `기타`는 0이면 막대를 그리지 않는다. 새 졸업생이 어느 범주에도 안 맞으면 빠지지 않고 `기타`로 잡힌다.
- 표기: 가로 막대, 범주명 + 대표 기관 약칭 + 인원수. 제목 "졸업생 {N}명의 현재 소속"(N 자동). **연도 범위는 표기하지 않는다**(제공 차트의 "2024–2026" 오류를 반복하지 않기 위해). 각주 "출처: 이 페이지의 Alumni 목록(빌드 시 집계)".
- 집계·분류 로직은 순수 함수로 분리해 단위 테스트한다.

## 7. 구조 (제안 — 빌더 재량)

- `src/components/nous/` 아래에 모달, People 카드, 메인 카드, 차트 2개를 둔다. 노스 메타데이터(이름·역할·문단·시각)는 이 폴더의 상수 모듈 하나.
- 노스는 CMS `members` 컬렉션에 넣지 않는다(이유: 음성·모달 등 다른 멤버에 없는 동작, CMS 스키마 변경 불필요). **People 페이지 섹션 카운트·Alumni 정렬 등 기존 로직에 영향 없음**.
- 모달은 페이지당 1개, 진입점은 `data-nous-open` 같은 속성으로 연결. 메인 페이지 모달에서도 진로 차트가 나와야 하므로 차트 컴포넌트가 직접 `getCollection`을 호출하는 편이 단순하다.
- 새 파일 첫 줄은 한국어 역할 주석(프로젝트 규칙).

## 8. 제약

- Astro 5 + Tailwind 4 + TS strict. 새 런타임 의존성 추가 없음(차트는 손으로 SVG, 애니메이션은 CSS/WAAPI).
- 검증: `npm run check` 0 에러, `npm run build` 통과, 진로 집계 단위 테스트(저장소에 테스트 러너가 없으므로 `node:test` + `node:assert` 파일을 `npx tsx --test`로 실행, 새 의존성 없음), 브라우저 실측 — 데스크톱/390px 모바일에서 모달 열기·재생·자막 이동·차트 등장·종료 후 CTA·닫기 시 정지, 가로 오버플로 0(`scrollWidth`).
- 배포는 main push → Cloudflare Pages 자동. push는 사용자 확인 후.

## 9. 빌더에게 맡기는 것

## 10. 제 판단으로 정한 것 (사용자 검토용)

- AI 고지 문구와 `AI` 배지.
- 자막 = 문단 강조형 transcript, 차트 = 해당 문단에서 순차 등장.
- 진로 범주 5개와 분류 키워드, "연도 범위 미표기".
- 노스를 CMS 밖 고정 데이터로 둠.
- 메인 카드 문구 "AI 연구보조원 노스가 연구실을 소개합니다".
- 음성 끝 잘린 단어 제거(79.2s 컷), 모달 전체 검색 색인 제외, 테스트는 `node:test` + tsx.
