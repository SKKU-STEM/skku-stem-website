# 노스 말하는 영상 · 한국어 기본/영어 선택 — 설계 (2026-10-17)

`2026-10-16-nous-member-card-design.md`(1차)를 바탕으로 바꾸는 부분만 적는다. 적지 않은 것은 1차 설계 그대로다.

## 왜

사용자의 원래 계획은 "노스가 사진 속에서 영상으로 말하고, 목소리는 20대 젊은 남성"이었다. 1차는 사진 + 음성 크기에 맞춘 빛 효과로 대신했고, v1 음성은 중년 남성처럼 들렸다. 이번에 영상·목소리를 바꾸고, 기본 발화를 한국어로 하되 영어를 고를 수 있게 한다.

## 정해진 것 (사용자 결정)

- 목소리: ElevenLabs **Taehyung**, eleven_v4. 원고는 v2(`docs/nous-script-v2.md`) — 한국어 낭독판 + 영어판.
- 영상: Higgsfield **Wan 2.7**(Starter 구독 크레딧, MCP). 사진을 첫 프레임으로, 낭독 음성을 넣어 입을 맞춘다. 15초 한도라 언어마다 8조각으로 만들어 잇는다.
- 기본은 한국어, 선택하면 영어.

## 만드는 것

### 영상 파일
- `public/nous/intro-ko.mp4`, `public/nous/intro-en.mp4` — 조각을 이어 붙이고(이음매는 문장 사이 쉼에서 0.25초 크로스페이드), 소리는 생성 영상의 소리가 아니라 **원본 낭독 트랙**(`nous-ko.mp3`/`nous-en.mp3`)을 그대로 넣는다. 입 맞춤의 기준과 소리가 정확히 같다.
- 인코딩: H.264, 480×640(3:4), AAC 모노 96kbps, `+faststart`. 화면에서 영상은 최대 240px 폭이라 480px이면 2배 밀도로 충분하다. 목표 용량 언어당 5MB 이하.
- 포스터: 한국어 영상 첫 프레임 → `src/assets/nous/video-poster.jpg`(빌드 때 webp). 영상과 같은 구도라 재생이 시작될 때 튀지 않는다.
- 기존 `public/nous/intro.mp3`(v1)는 지운다.

### 데이터(`nous.ts`)
- `type Lang = 'ko' | 'en'`, 기본 `'ko'`.
- `VOICE` → `VOICES: Record<Lang, { src, duration, label, spoken }>`.
- `PARAGRAPHS[i].start` → `start: Record<Lang, number>`. 문단 수·순서는 두 언어가 같다(5문단). 그래서 그래픽(`GRAPHIC_AT`)·CTA(`CTA_AT`)는 문단 번호 기준 그대로 두고, 시각만 언어별로 다르다.
- `en`·`ko` 글은 v2 원고(자막용 표기: SKKU-STEM, KIST, youngmk@skku.edu 등).
- `activeParagraph(t, lang)`, `visibleGraphics(t, lang)`, `ctaExpanded(t, ended, lang)`로 언어를 받는다.
- 엔벌로프는 언어별 두 개(`ENVELOPES.ko/en`). 생성기는 두 트랙을 처리한다.

### 모달
- 사진(`<Image>`) 자리에 `<video data-nous-media playsinline preload="none" poster>`. 같은 크기·둥근 모서리·AI 칩·음성 빛 효과 유지. FLIP 고스트는 썸네일 사진에서 이 영상 자리로 떠오른다.
- 언어 선택: 이름 아래에 `한국어 | English` 두 버튼(`aria-pressed`). 열 때마다 한국어로 시작.
  - 바꾸면 **지금 문단의 시작**으로 같은 문단을 새 언어로 이어 재생한다(처음부터 다시 듣지 않게). 정지 상태였으면 정지 유지.
  - 길이·시각 표시·문단 시각 버튼·슬라이더 최대값이 새 언어 값으로 바뀐다.
- 자막: 말하는 언어가 위(본문 크기), 다른 언어가 아래(작게). 한국어 모드 = 한국어 위 / 영어 아래, 영어 모드 = 지금과 같음.
- 안내 문구: "한국어 음성 · 영어 병기" / "English voice · 한국어 자막".
- 공개 문구: "영상과 음성은 AI로 만들었습니다." / "Video and voice are AI-generated."
- 오류 문구: "영상을 불러오지 못했습니다…".

### 카드 문구
- People: "Watch lab intro · 1:32"(한국어 길이).
- 메인: 버튼 "연구실 소개 보기", 캡션 "한국어 음성 · 영어 선택 · 1:32".

## 하지 않는 것

- 언어 선택을 기억하지 않는다(열 때마다 한국어). 사이트에 언어 전환 기능이 없어 맞출 기준이 없다.
- 카드 썸네일은 사진 그대로(영상 자동재생 없음 — 데이터·배터리).
- 모바일 영상 크기는 1차(5rem) 그대로. 실제 폰에서 작아 보이면 따로 키운다(390×664 높이 제약 때문에 1차에서 줄인 값).

## 검증

- 단위: 언어별 문단 판정·그래픽·CTA 경계, 시각 버튼 값.
- 브라우저(Chromium·WebKit × 1280·390 × 두 페이지): 1차 198건 + 언어 전환(같은 문단 이어 재생, 시각 표시 갱신, 정지 유지), 영상 프레임이 실제로 바뀌는지(재생 중 `currentTime` 증가와 프레임 해시 변화), iOS 대비 `playsinline` 존재.
- 용량: 두 mp4 합계 10MB 이하, 첫 화면 로드에 영상 요청 없음(`preload="none"`).
